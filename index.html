Tiempo por pendiente

Intervalos de 5 puntos porcentuales, con 0 % en el centro. El rango se amplía automáticamente si la carrera supera ±30 %.

Intensidad relativa al umbral

FC relativa = FC/LTHR. Velocidad relativa = velocidad observada / velocidad de ritmo umbral.

Índice de dificultad de progresión (IDPT)

Toca o desliza sobre un tramo para ver sus datos.
Caja = 25–75 % del grupo · línea = mediana · bigotes = rango. Desliza horizontalmente para recorrer la carrera; toca un tramo para seleccionarlo y mostrar su valor.
